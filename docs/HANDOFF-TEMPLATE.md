# T06 handoff

## 1. Goal

State one bounded card, acceptance ID set, or review objective.

## 2. Current state

List the exact behavior that works, the project phase, and relevant versions.

## 3. Run commands

Include the working directory, install command, application command, and checks.

## 4. Passed acceptance IDs

List only checks actually executed, with observable evidence.

## 5. Failed or unrun acceptance IDs

Separate failures from unrun checks and give the first useful error.

## 6. Next action

Give the smallest safe next step.

## 7. Do not change

List fixed expectations, privacy boundaries, migration invariants, and out-of-scope work.

## 8. Changed files

Explain why each changed file exists.

## 9. Git state

Record the start commit, end commit when available, and every uncommitted path.
