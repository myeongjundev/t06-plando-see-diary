# T06 준비용 통과 기준표

상태: **공식 카드 공개 전 초안**

## 카드 1 · 기록의 구조

| ID | 입력·행동 | 기대 결과 | 증거 |
|---|---|---|---|
| T06-C1-01 | 필수 필드가 채워진 합성 기록 추가 | 새 UUID 한 건이 목록과 요약에 반영 | 화면·API 결과 |
| T06-C1-02 | 기존 기록의 값 수정 | 해당 ID 한 건과 관련 요약만 변경 | 수정 전후 대조 |
| T06-C1-03 | 기존 기록 삭제 | 해당 ID 한 건만 사라지고 요약 재계산 | 삭제 전후 대조 |
| T06-C1-04 | 필수값 없이 저장 | 저장 거부와 구체적 이유 표시 | 오류 화면 |
| T06-C1-05 | 화면 확인 | 단위와 `Asia/Seoul` 표시 | 공개 화면 |

## 카드 2 · 내보내기와 전체 삭제

| ID | 입력·행동 | 기대 결과 | 증거 |
|---|---|---|---|
| T06-C2-01 | 합성 기록 5건 저장 후 새로고침 | ID·날짜·값·단위가 동일 | 전후 대조표 |
| T06-C2-02 | JSON 내보내기 후 복원 | 기록 5건이 중복 없이 복원 | 내보낸 파일·대조표 |
| T06-C2-03 | 전체 삭제 확인 | 저장소와 화면 모두 0건 | 삭제 결과 |
| T06-C2-04 | 손상 JSON 가져오기 | 기존 기록 불변, 오류 이유 표시 | 해시·건수 전후 비교 |

## 카드 3 · v1 → v2 변환

| ID | 입력·행동 | 기대 결과 | 증거 |
|---|---|---|---|
| T06-C3-01 | v1 합성 기록 5건 불러오기 | ID·날짜·값·단위 보존, 새 필드 기본값 | 필드 대응표 |

## 카드 4 · 날짜와 잘못된 값

| ID | 입력·행동 | 기대 결과 | 증거 |
|---|---|---|---|
| T06-C4-01 | 월요일 00:00 KST 기록 | 해당 주 첫 기록으로 포함 | 예상·실제 표 |
| T06-C4-02 | 일요일 23:59 KST 기록 | 해당 주 마지막 기록으로 포함 | 예상·실제 표 |
| T06-C4-03 | 잘못된 날짜·숫자 아닌 값 | 저장·집계에서 제외되고 이유 표시 | 오류 목록 |
| T06-C4-04 | 중복 UUID | 정한 규칙대로 거부 또는 교체, 중복 집계 없음 | 중복 검사 |
| T06-C4-05 | 누락값 | 필수값이면 거부, 선택값이면 기본값 | 규칙표 |

## 카드 5 · 실제 날짜 5일

| ID | 입력·행동 | 기대 결과 | 증거 |
|---|---|---|---|
| T06-C5-01 | 서로 다른 실제 날짜 5일에 로컬 기록 | 날짜 5개와 가린 요약 존재 | 로컬 원본·가린 제출본 |
| T06-C5-02 | 반복 불편 한 가지 선택·수정 | 개선 전후 행동 차이가 설명됨 | 개선 기록 |
| T06-C5-03 | 잘못 입력한 한 건 수정 | 해당 행과 관련 요약이 같은 화면에서 변경 | 전후 화면 |
| T06-C5-04 | 작업시간 집계 | 기다린 날짜는 5~6시간 능동 작업에서 제외 | 작업 로그 |

## 공개 합성 자료 초안

- 정상 기록 5건
- 월요일 00:00 경계 1건
- 일요일 23:59 경계 1건
- 중복 UUID 1건
- 잘못된 날짜 1건
- 숫자가 아닌 값 1건
- 필수값 누락 1건
- v1 기록 5건과 대응하는 v2 기대 결과

공식 과제가 공개되면 검사 ID·입력·기대값을 최신 카드에 맞춰 최종 고정한다.
