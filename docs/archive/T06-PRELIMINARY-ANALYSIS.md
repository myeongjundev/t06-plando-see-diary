# T06 사전 자료 분석

상태: **PRELIMINARY / 공식 과제 공개 전**

## 사전안의 목표

습관·운동·게임·학습 시간처럼 사용자가 실제로 남기고 싶은 항목을 기록하고,
정확한 한 건을 수정·삭제한 뒤 다시 불러오는 개인 기록기를 만든다. 공개 결과물에는
실제 개인 기록을 올리지 않고 합성 자료만 사용한다.

## 완료 기준

1. 공개 주소에서 합성 기록을 추가·수정·삭제할 수 있다.
2. 기록 변경이 목록과 요약값에 동시에 반영된다.
3. 내보내기·가져오기·전체 삭제가 화면에 보인다.
4. 실제 개인 기록과 개인정보가 공개되지 않는다.

## 카드별 핵심

| 카드 | 구현 목표 | 반드시 남길 증거 |
|---|---|---|
| 1 · 기록 구조 | ID·날짜·시간대·항목·값·단위·메모 CRUD | 필드 정의표, 합성 기록 3건, CRUD 검사 |
| 2 · 보존과 복구 | 새로고침 유지, JSON 내보내기·복원·전체 삭제 | 합성 기록 5건, 복원 전후 대조, 손상 파일 거부 |
| 3 · 자료 변경 | schemaVersion과 새 필드, v1 → v2 변환 | v1/v2 자료, 필드 대응표, 반복 변환 검사 |
| 4 · 날짜와 오류 | KST 주간 집계, 경계·누락·중복·잘못된 값 처리 | 예상 결과표와 실제 검사 결과 |
| 5 · 5일 사용 | 실제 날짜 5일 사용 후 불편 한 가지 개선 | 가린 5일 요약, 개선 전후, 수정 행·요약 대조 |

## 전체 과정 개요와 다른 점

| 항목 | 전체 과정 개요 | 이번 사전안 | 공식 공개 때 확인 |
|---|---|---|---|
| 계획시간 | 8~10시간 | 5~6시간 | 최종 시간 예산 |
| 제품 구조 | Plan → Do → See | 개인 기록 CRUD와 주간 요약 | Plan/Do/See 필수 범위 |
| 저장소 | 실제 서버 DB | 새로고침 유지, 실제 원자료는 PC | PostgreSQL 필수 여부 |
| 데이터 계약 | `contracts/pds-schema-v2.json` 명시 | schemaVersion과 v1/v2 변환만 명시 | 파일명·위치 필수 여부 |
| 삭제·복원 | 내보내기·전체 삭제·복원 | 동일 | 공통 요구로 준비 가능 |
| 공개 데이터 | 링크를 아는 사람이 볼 수 있음 | 합성·가림 자료만 공개 | 실제 자료 서버 저장 금지 여부 |
| 사용 기간 | T06 자체 기간 설명이 달랐음 | 서로 다른 실제 날짜 5일 | 시작일과 누락일 규칙 |

## 지금 고정해도 안전한 원칙

- 시간대는 `Asia/Seoul`로 표시하고 계산한다.
- 주는 월요일 00:00부터 일요일 23:59:59까지로 정의한다.
- 배열 순번이 아니라 UUID로 정확한 기록을 수정·삭제한다.
- 가져오기는 전체 파일을 검증한 뒤 한 번에 반영한다.
- 손상 파일은 기존 기록을 전혀 바꾸지 않는다.
- v1 변환은 원본 필드를 보존하고 여러 번 실행해도 결과가 같다.
- 공개 배포에는 합성 자료만 넣는다.
- 실제 5일 기록은 로컬에 두고 제출물에는 가린 집계만 남긴다.
- 기다린 5일은 능동 작업시간에 포함하지 않는다.

## 사용 항목 후보

공식 공개 뒤 사용자가 직접 하나를 결정한다.

| 후보 | 값·단위 예시 | 장점 | 주의점 |
|---|---|---|---|
| 학습 세션 | 45분 | 과정과 연결되고 매일 기록하기 쉬움 | 과목·메모에 개인정보를 쓰지 않음 |
| 운동 | 30분 또는 3km | 요약값이 직관적 | 서로 다른 단위를 한 합계로 섞지 않음 |
| 집중 작업 | 2회 | 단순하고 공개 합성 자료 제작이 쉬움 | 무엇을 1회로 셀지 규칙 필요 |

현재 추천은 **학습 세션 시간(분)**이다. 다만 이는 사용자 판단 항목이므로 공식
과제가 열리기 전에는 확정하지 않는다.

## 공식 공개 직후 확인 순서

1. 최신 원문을 이 문서와 대조한다.
2. 계획시간·DB·Plan/Do/See·계약 파일의 최종 요구를 확인한다.
3. 기록 항목과 단위를 사용자가 결정한다.
4. 합성 자료와 검사 기대값을 구현 전에 고정한다.
5. 카드 1을 완성한 실제 날짜부터 5일 기록을 시작한다.
