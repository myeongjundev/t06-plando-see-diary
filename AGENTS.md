# T06 shared agent instructions

These rules apply to Codex and any other coding agent working in this repository.

1. Read `docs/STATUS.md`, `docs/REQUIREMENTS.md`, and `docs/DECISIONS.md` before
   changing implementation files.
2. The project is preliminary until `docs/REQUIREMENTS.md` says the official T06
   assignment has been reconciled. Before that point, do not implement or deploy.
3. Keep real personal diary records outside the repository and public deployment.
   Use synthetic fixtures in code, screenshots, tests, exports, and submissions.
4. Do not add authentication in T06. Preserve a clean extension boundary for T07.
5. Do not weaken, remove, or rewrite a fixed acceptance expectation to make code pass.
6. Import must be atomic; migration must preserve values and be idempotent; weekly
   aggregation follows the documented Asia/Seoul rule.
7. Before handoff, update `docs/STATUS.md` and use `docs/process/HANDOFF-TEMPLATE.md`.
8. Do not commit chat transcripts, secrets, generated dependency folders, private
   exports, or real diary data.

Detailed workflow and architecture are documented under `docs/`.
